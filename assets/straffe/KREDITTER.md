# Kreditter for straffekonken

- `spiller.glb`: figuren «X Bot» fra Mixamo (Adobe), hentet fra Babylon.js sitt ressursbibliotek
  (github.com/BabylonJS/Assets, CC BY 4.0). Animasjonene idle, run og walk følger med derfra.
  Animasjonene «Soccer Penalty Kick», «Goalkeeper Idle» og «Goalkeeper Diving Save» er lastet ned fra
  mixamo.com og lagt over på samme figur. Mixamo-innhold kan brukes fritt i egne spill og prosjekter.
- `environment.env`: miljølys fra Babylon.js sin playground (github.com/BabylonJS/Babylon.js, Apache 2.0).

Drakter, nummer og hår males på figuren i koden (KitPlugin i benjamin.html), så filen kan brukes til alle spillerne.
